Economic Assumptions Files
--------------------------

This directory contains an example of an economic assumptions file
that can be combined and modified to construct your own economic
assumptions files that are stored on your local computer.

Such an economic assumptions file can then be used by the `tc`
command-line interface to Tax-Calculator using the `--assump` option
or be read in a Python program that imports the Tax-Calculator
`taxcalc` package, as described in the [user
guide](https://taxcalc.pslmodels.org/guide/index.html#user-guide).

[This
document](https://github.com/PSLmodels/Tax-Calculator/blob/master/taxcalc/assumptions/ASSUMPTIONS.md)
provides access to a template economic assumptions file and guidelines
about how to prepare your own assumptions files.
